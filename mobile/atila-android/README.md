# Attila Mobile

Agent Android local Attila + Neo-Attila pour les appareils explicitement autorisés par leur propriétaire.

Première étape :
- diagnostic local de l'appareil ;
- inventaire des applications visible via les API Android autorisées ;
- état Android et niveau de correctif de sécurité ;
- rapport conservé dans l'espace privé de l'application ;
- aucune suppression silencieuse ;
- aucun contournement des protections Android ;
- aucun verdict malware sans moteur de détection fiable ;
- aucune action contre une machine distante.

Les actions de quarantaine ou suppression futures passent uniquement par les API Android prévues à cet effet et les autorisations utilisateur/administrateur requises.
