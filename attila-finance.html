Attila Finance Lab

Laboratoire de stratégies sur les marchés financiers internationaux.

SIMULATION UNIQUEMENT. Aucun argent réel, aucune connexion à un courtier, aucun revenu garanti. Ne saisissez pas de clé API ni de données bancaires.

Tester une stratégie de survie

Collez des données historiques au format JSON : tableau de bougies avec open, high, low, close. Au moins 22 lignes, maximum 500. Données à fournir par vous-même, sans connexion automatique aux marchés.

En attente de données historiques.

API de simulation

GET /api/attila-finance : état du moteur.

POST /api/attila-finance : simulation avec {"action":"simulate","market":"DEMO","bars":[...]}.

La stratégie est expérimentale. Les résultats historiques ne préjugent pas des performances futures. La simulation ne constitue pas un conseil en investissement.
