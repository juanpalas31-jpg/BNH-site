# Spider Vault

The Spider Vault is the physical Source Anchor for the family Spider lineage.

It is simultaneously:
- a ceremony environment;
- a reconstruction and verification point;
- an archive for authenticated founder material;
- an Armor G0 archive;
- a future-generation workspace.

The Vault is **not** the only surviving copy of Spider. Eggs and recovery material must exist in separate failure domains.

The public repository never stores the real address, access credentials, private guardian identities, private family records, or cryptographic recovery secrets.

Rendering technology may evolve across decades. The authenticated founder source and the historical order of the first awakening remain preserved.

Property acquisition is never automatic and remains subject to verified finances plus legal, tax, insurance and professional review.
