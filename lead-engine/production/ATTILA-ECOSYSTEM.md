# Attila Financial Nature — family-private design
Financial data is mapped into a natural habitat metaphor. A safe label is never a guarantee.
Attila is the mother orchestrator. Neo-Attila hatchlings inherit a versioned, explicit DNA feature list.
Fourmi Tila is a separate, disabled-by-default observer colony concept.
## API
/api/attila-ecosystem (GET, POST) requires header x-attila-family-key matching the server-side ATTILA_FAMILY_API_KEY (minimum 32 chars). Without configuration the endpoint returns 503 and denies access.
POST actions: hatch {id,generation}; habitat {symbol,bars}; brief {habitats,scouts}.
No persistent account management, brokerage integration, market feed, scheduler, or live trading is present.
The listed family names define intended membership only; they do not verify identity. Production requires individual accounts, MFA, role-based permissions, consent, and audit logs.
Future legal assessment is required before brokerage or investment functionality. No returns are promised.
