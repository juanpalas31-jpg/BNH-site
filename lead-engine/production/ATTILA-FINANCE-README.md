# Attila Finance Lab (isolated reserve)
- App: /attila-finance.html
- API: GET and POST /api/attila-finance
- Simulator: attila-financial-survival-simulator.js
- Mode: paper trading only; no broker connection or real orders.
- Input: user-supplied historical OHLC candles (22–500). No external API keys or brokerage credentials.
- The backtest is experimental and does not validate profitability.
- Before production: implement authenticated access, rate limits, durable research records, independent historical feed, reproducible tests, out-of-sample validation, and a separate risk/legal review.
- This project is separate from Bilan Habitat leads, pages and prospect records.
